# Mandelbrot Set

A visualization of the **Mandelbrot set** implemented with HTML and JavaScript.

The goal of this project is to explore both the mathematical foundations of the Mandelbrot set and its technical implementation in the browser.

The Mandelbrot set will be calculated pixel by pixel and rendered using the **HTML Canvas API**.

To improve performance, the project will use multiple **Web Workers** to calculate individual pixel rows in parallel.

## Technologies

- HTML
- JavaScript
- HTML Canvas
- Web Workers
